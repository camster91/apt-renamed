# apt-renamed

A small public-repository GitHub Actions probe. Its workflows are manually dispatched jobs that print fixed messages.

## Run a probe

When GitHub Actions is enabled for this repository, open **Actions**, choose **Probe** or **Probe2**, and select **Run workflow**. The jobs do not check out source, read secrets, write repository contents, or deploy anything.

This is a disposable diagnostic repository, not an application or package. It has no releases or supported software versions.
